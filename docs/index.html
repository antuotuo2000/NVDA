区分短期估值冲击与长期价值变化。

护城河是否依赖单一个人？

CUDA生态、研发团队与客户基础不会因CEO交接立即消失。真正需要检验的是长期技术路线、客户关系与组织执行能否延续。

现金流能否持续增长？

若自由现金流与竞争优势保持稳定，变化可能主要影响短期风险溢价；若产品竞争力或核心人才持续流失，则可能影响长期内在价值。

不能预先断言“没有黄仁勋就应降多少倍PE”。合理估值需要同时重估增长、利润率、资本投入、竞争风险和折现率。
